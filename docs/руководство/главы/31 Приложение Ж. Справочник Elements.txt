# Приложение Ж. Справочник Elements
Все функции, типы и константы заголовка `elements.h` — по группам, в порядке заголовка. Размеры — в точках экрана (масштаб HiDPI библиотека учитывает сама), тексты — строки UTF-8, цвета — числа `0xRRGGBB`. Объяснения с примерами — в главе 24, готовые программы — в `examples\elements\demos`.

## Подключение и типы

:= Что | Значение
: `#include <elements.h>` | весь интерфейс; в WinCC строкой `#pragma comment(lib, "elements")` подключает исходники `lib\elements`, строкой `#pragma comment(linker, "/SUBSYSTEM:WINDOWS")` делает программу оконной даже с `main`
: `el` | элемент — число `int`; 0 — нет элемента; родитель 0 — само окно
: `el_fn` | обработчик: `void f(el e, void *arg)`; `e` — элемент события, `arg` — указатель, переданный при подписке
: рисование | `void f(el e, int w, int h, void *arg)` — для `el_paint` и `el_window_canvas`; `w`, `h` — размер поверхности

## Константы

:= Константа | Значение | Где
: `EL_STRETCH` | 0 | `el_align`: растянуть на всю ячейку
: `EL_START` | 1 | `el_align`: к левому или верхнему краю
: `EL_CENTER` | 2 | `el_align`: посередине
: `EL_END` | 3 | `el_align`: к правому или нижнему краю
: `EL_LEFT` | 0 | `el_dock_side`: к левой стороне
: `EL_TOP` | 1 | `el_dock_side`: к верхней
: `EL_RIGHT` | 2 | `el_dock_side`: к правой
: `EL_BOTTOM` | 3 | `el_dock_side`: к нижней
: `EL_LINEAR` | 0 | анимация: равномерно
: `EL_EASE_IN_OUT` | 1 | анимация: плавный разгон и торможение
: `EL_EASE_OUT` | 2 | анимация: быстро в начале, плавно в конце
: `EL_OVERSHOOT` | 3 | анимация: с перелётом и возвратом
: `EL_BOUNCE` | 4 | анимация: с отскоками в конце
: `EL_EASE_IN` | 5 | анимация: плавно в начале
: `EL_SHIFT` | 1 | `el_mods`: зажат Shift
: `EL_CTRL` | 2 | `el_mods`: зажат Ctrl
: `EL_ALT` | 4 | `el_mods`: зажат Alt

## Окно и цикл

:= Функция | Что делает
: `el el_window(const char *title, int w, int h)` | создаёт окно размером `w × h` точек и возвращает его элемент; само окно раскладывает детей как `el_dock`
: `void el_title(const char *title)` | сменить заголовок окна
: `int el_frame(void)` | один кадр: ввод, события, раскладка, рисование; 0 — окно закрыто. Для своего цикла: `while (el_frame()) { … }`
: `void el_run(void)` | кадры, пока окно не закроют; когда ничего не происходит, окно спит
: `void el_on_close(el_fn fn, void *arg)` | при закрытии окна звать `fn` вместо выхода; закрыть потом — `el_quit`
: `void el_quit(void)` | закрыть окно: следующий `el_frame` вернёт 0, `el_run` кончится

## Нестандартные окна

:= Функция | Что делает
: `void el_frameless(int on)` | 1 — без системной рамки: заголовок, кнопки и фон рисует программа
: `void el_window_round(int radius)` | скруглить углы окна на `radius` точек; 0 — прямые
: `void el_window_shape(const char *shape)` | форма: `"rect"`, `"round:24"`, `"ellipse"`, `"pixels"` — контур по непрозрачности нарисованного
: `void el_window_region(const int *xy, int count)` | любой многоугольный контур: `count` пар `x, y` в точках
: `void el_window_aspect(int w, int h)` | держать пропорции `w : h` при изменении размера; 0, 0 — свободно
: `void el_window_opacity(int alpha)` | прозрачность всего окна 0–255
: `void el_drag_region(el e)` | тянут за элемент `e` — двигается всё окно (своя шапка)
: `void el_window_minmax(int minw, int minh, int maxw, int maxh)` | пределы размера; -1 — без предела
: `void el_window_resizable(int on)` | можно ли менять размер; по умолчанию да; безрамочное окно тянут за края
: `el el_window_canvas(void (*fn)(el e, int w, int h, void *arg), void *arg)` | поверхность во весь фон окна: рисунок функциями `el_g_*`

Форма окна пересчитывается при каждом изменении размера.

## Эффекты окна

:= Функция | Что делает
: `void el_effect(const char *name, int amount)` | включить эффект силой `amount`; 0 — выключить. Можно несколько сразу
: `void el_effects_clear(void)` | выключить все эффекты

:= Имя эффекта | Что делает
: `"dispersion"`, `"chromatic"` | расщепление цветовых каналов
: `"scanlines"` | строки развёртки
: `"noise"` | шум
: `"vignette"` | затемнение краёв
: `"glitch"` | глитч, анимированный
: `"bloom"`, `"glow"` | свечение ярких мест
: `"pixelate"` | крупные пиксели
: `"grayscale"` | чёрно-белое
: `"sepia"` | сепия
: `"invert"` | обращение цветов

Эффект действует на весь кадр, вместе с текстом.

## Панели

:= Функция | Что делает
: `el el_stack(el parent, int horizontal)` | дети друг за другом: 0 — сверху вниз, 1 — слева направо; промежуток — `el_gap`
: `el el_dock(el parent)` | дети прижимаются к сторонам по `el_dock_side`, последний занимает остаток
: `el el_wrap(el parent)` | дети в строку с переносом
: `el el_grid(el parent, const char *cols, const char *rows)` | сетка; размеры через запятую: `Auto` — по содержимому, число — в точках, `*` — остаток, `2*` — вдвое больший остаток
: `el el_scroll(el parent)` | один ребёнок с прокруткой колесом и ползунком
: `el el_canvas(el parent)` | дети стоят там, где велит `el_pos`
: `el el_border(el parent)` | рамка и фон вокруг одного ребёнка; для нескольких — положить в неё панель
: `el el_group(el parent, const char *header)` | рамка с заголовком
: `el el_tabs(el parent)` | вкладки
: `el el_tab(el tabs, const char *header)` | вкладка; её содержимое кладут в неё как в панель

Ячейки столбцов известной ширины меряются с этой шириной: перенос текста и `el_wrap` в сетке делятся на строки, строки `Auto` растут под них.

В полях: выделение мышью и Shift со стрелками, Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V, Home и End; в многострочном — стрелки по строкам.

## Шрифты

:= Функция | Что делает
: `int el_font_add(const char *name, const char *path)` | загрузить `.ttf` или `.otf` и дать имя; 1 — удалось
: `int el_font_add_memory(const char *name, const void *data, int size)` | то же из байтов шрифта в памяти — шрифт внутри `.exe`
: `void el_font_face(el e, const char *family)` | шрифт элемента по имени: `"default"` (Segoe UI), `"mono"` (Consolas) или загруженное

Каждый загруженный шрифт — в своём наборе: имя всегда значит тот файл, из которого его загрузили. Тридцать шрифтов Elements — в `examples\elements\fonts`: Elm Grotesk (Light, Bold, Black, Italic, Condensed, Extended), Elm Compressed, Elm Geometric (Light, Bold), Elm Humanist (Bold, Italic), Elm Rounded (Bold), Elm Techno (Bold), Elm Mono (Bold), Elm Typewriter, Elm Slab (Bold), Elm Serif (Bold, Italic), Elm Didone, Elm Oldstyle, Elm Hairline, Elm Wide Light.

## Свойства стиля

Строка для `el_style` и правил таблицы: свойства через пробел, у каждого — имя, двоеточие, значение.

:= Свойство | Значение
: `background:#223` | цвет фона
: `color:#fff` | цвет текста
: `border:#456` | цвет рамки
: `border-width:1` | толщина рамки
: `radius:6` | скругление углов
: `padding:4 8` | внутренний отступ: одно, два или четыре числа
: `margin:0 0 8 0` | внешний отступ
: `width:120`, `height:32` | размер
: `gradient:#1a2a6c #b21f1f vertical` | градиент двух цветов: `vertical`, `horizontal` или `diagonal`
: `background-alpha:160` | прозрачность фона 0–255 — «стекло»
: `background-image:путь` | картинка фоном
: `shadow:#000 18 0 6 120` | тень: цвет, размытие, сдвиг x, сдвиг y, сила; `shadow:none` — без тени
: `hover-background`, `press-background` | фон под мышью и при нажатии
: `hover-color`, `hover-border` | цвет текста и рамки под мышью
: `font-size:16` | размер шрифта
: `font-weight:bold` | жирный
: `font-family:mono` | шрифт по имени; имя может быть из нескольких слов
: `text-align:center` | выравнивание текста: `center` или `right`

## Таблица стилей

:= Функция | Что делает
: `void el_stylesheet(const char *css)` | правила для всего окна: `"button{radius:10} .card{background:#fff;background-alpha:28} #title{font-size:28}"`
: `int el_stylesheet_file(const char *path)` | правила из файла; 1 — прочитан
: `void el_class(el e, const char *classes)` | классы элемента через пробел: `"card big"`

Выборщики: вид элемента (`button`), класс (`.card`), имя (`#title`), вид с классом (`button.big`). Собственные настройки элемента сильнее правил таблицы.

## Анимации и таймеры

:= Функция | Что делает
: `void el_animate(el e, const char *prop, int from, int to, int ms, int easing, int loop)` | анимация свойства: `"opacity"` 0–255, `"x"` и `"y"` — сдвиг в точках, `"scale"` — в процентах, `"rotate"` — в градусах; `loop`: 0 — один раз, 1 — по кругу, 2 — туда и обратно

: `int el_every(int ms, el_fn fn, void *arg)` | звать `fn` каждые `ms` миллисекунд; возвращает номер таймера
