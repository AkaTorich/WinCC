# Об этой книге
WinCC — компилятор языка Си для Windows. Из файлов с текстом программы он делает обычные программы Windows: консольные, оконные и библиотеки DLL. Готовой программе не нужно ничего, кроме самой Windows: всё, что программа берёт из библиотеки Си, уже внутри неё.

Эта книга — руководство для того, кто пишет на WinCC. Первая часть ставит компилятор и проводит через первую программу, окно редактора и командную строку. Вторая рассказывает, какой Си понимает компилятор и что умеет его библиотека, как обращаться с кириллицей и как вставить в программу команды процессора. Третья часть — программы для Windows: окна и сообщения, свои DLL, функции любых DLL системы, рисование.

Четвёртая часть посвящена WUI — библиотеке, которая даёт программе на Си красивое окно в одной из шестидесяти одной темы ThemeLibrary: стекло, приборы, пергамент, камень, экраны. Пятая — сети: скачать страницу, соединить две программы, поднять свой веб-сервер. В приложениях собраны справочники: ключи компилятора, его сообщения, заголовки, все функции WUI и сети, ограничения.

Каждый пример в книге собран этим компилятором. Его можно набрать, нажать «Собрать» и получить ту же программу.
