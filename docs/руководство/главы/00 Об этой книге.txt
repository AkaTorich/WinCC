# Об этой книге
WinCC — компилятор языка Си для Windows с окном для работы: редактором, проектами и отладчиком. Из файлов с текстом программы он делает обычные программы Windows: консольные, оконные, библиотеки DLL и свои библиотеки `.lib`. Готовой программе не нужно ничего, кроме самой Windows: всё, что программа берёт из библиотеки Си, уже внутри неё.

Эта книга — руководство для того, кто пишет на WinCC. Первая часть ставит компилятор и проводит через первую программу, окно редактора и командную строку. Вторая рассказывает, какой Си понимает компилятор и что умеет его библиотека, как обращаться с кириллицей и как вставить в программу команды процессора. Третья часть — программы для Windows: окна и сообщения, свои DLL, функции любых DLL системы, рисование.

Четвёртая часть посвящена WUI — библиотеке, которая даёт программе на Си красивое окно в одной из шестидесяти одной темы ThemeLibrary: стекло, приборы, пергамент, камень, экраны. Пятая — сети: скачать страницу, соединить две программы, поднять свой веб-сервер. Шестая — отладчик окна WinCC, свои библиотеки `.lib` и окна на Elements — второй библиотеке окон, со своими формами окон, эффектами и тридцатью шрифтами. В приложениях собраны справочники: ключи компилятора, его сообщения, заголовки, все функции WUI, сети и Elements, ограничения.

Каждый пример в книге собран этим компилятором. Его можно набрать, нажать «Собрать» и получить ту же программу.
