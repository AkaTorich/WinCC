# Раскладка
В WUI нет координат: программа не говорит «кнопка в точке 400, 300». Она говорит «кнопки — в строку, строка — под списком, список забирает всё, что осталось», а WUI сама считает места при каждом изменении размера окна, смене темы или масштаба. Эта глава — о таких правилах: столбцы, строки, перенос, прокрутка и карточки; размер по содержимому, заданный и доля остатка; поля, промежутки и выравнивание. Освоив их, можно собрать окно любой сложности так, что оно останется аккуратным и в узком окне, и развёрнутым на весь экран.

## Как WUI считает места

Каждый элемент WUI лежит в каком-то родителе, и раскладка идёт по дереву сверху вниз в два прохода. Сначала замер: родитель спрашивает каждого ребёнка, сколько места ему нужно при доступной ширине. Надпись отвечает размером своего текста с переносом по этой ширине, кнопка — размером текста и значка с полями темы, поле ввода — высотой строки и шириной по умолчанию. Затем расстановка: родитель, зная желания детей и своё место, выдаёт каждому прямоугольник.

Отсюда главное правило: размер элемента по умолчанию — по содержимому. Кнопка «ОК» узкая, «Сохранить изменения» — шире, и программа об этом не заботится. Когда тема меняется, меняются шрифты и поля, и всё перекладывается само: в теме «Терминал» буквы моноширинные и шире, в «Пергаменте» заголовки набраны заглавными, но ничего не налезает друг на друга.

Порядок детей — порядок, в котором их создали. В том же порядке они рисуются и в том же порядке по ним ходит клавиша Tab. Вставить элемент между уже созданными нельзя; если нужен другой порядок — создавайте в нём.

## Столбец и строка

Два основных контейнера — столбец (`wui_column`) и строка (`wui_row`). Столбец кладёт детей сверху вниз, строка — слева направо. Столбец содержимого окна (`wui_content`) и карточка (`wui_card`) — тоже столбцы. Между детьми контейнер оставляет промежуток: у содержимого окна он 12 точек, у строки 10, у карточки 10, у простого столбца 0. Меняет его `wui_gap(контейнер, точки)`.

Вот форма ввода — типичная задача на столбцы и строки: подписи слева одной ширины, поля справа до края, кнопки внизу справа.

```
#include <wui.h>

// строка формы: подпись постоянной ширины и поле на весь остаток
static WuiControl *field(WuiControl *parent, const char *caption, const char *hint)
{
    WuiControl *row = wui_row(parent);
    WuiControl *label = wui_label(row, caption, WUI_LABEL_TEXT);
    wui_size(label, 90, 0);
    WuiControl *box = wui_textbox(row, hint);
    wui_stretch(box, 1);
    return box;
}

int main(void)
{
    WuiControl *win = wui_window("Новый контакт", 760, 460, "Contacts");
    WuiControl *page = wui_content(win);

    wui_label(page, "Новый контакт", WUI_LABEL_H1);
    WuiControl *card = wui_card(page, "Данные");
    field(card, "Имя", "Иван Петров");
    field(card, "Телефон", "+7 900 000-00-00");
    field(card, "Почта", "ivan@example.com");

    wui_spacer(page);                       // забирает остаток высоты

    WuiControl *buttons = wui_row(page);
    wui_spacer(buttons);                    // забирает остаток ширины
    wui_button(buttons, "Отмена", WUI_BUTTON_NORMAL);
    wui_button(buttons, "Сохранить", WUI_BUTTON_ACCENT);
    return wui_run();
}
```

@ 14-форма.png | Форма из строк: подписи одной ширины, поля до края, кнопки прижаты вправо и вниз

Здесь три приёма, на которых держится почти любая раскладка. Подпись получила постоянную ширину — 90 точек, поэтому поля во всех строках начинаются с одной линии, как бы ни различались слова «Имя» и «Телефон». Поле получило долю остатка — `wui_stretch(box, 1)` — и тянется до правого края строки. А пустые места (`wui_spacer`) забрали всё лишнее: по вертикали — между карточкой и кнопками, по горизонтали — слева от кнопок. Если растянуть окно, поля станут шире, кнопки уйдут вниз и вправо, а подписи останутся на месте.

Функция `field` — обычная функция Си, которая строит кусок дерева и возвращает нужный элемент. Повторяющиеся куски окна удобно делать так: строка формы, плитка, карточка с заголовком и кнопкой.

## Размер: по содержимому, заданный, наименьший

У каждого элемента три способа получить размер вдоль родителя.

:= Способ | Функция | Когда нужен
: По содержимому | ничего не делать | почти всегда: надписи, кнопки, флажки
: Заданный | `wui_size(c, ширина, высота)` | подписи формы, поле суммы, холст, боковая панель
: Не меньше | `wui_min_size(c, ширина, высота)` | плитки одной ширины при разной длине текста
: Доля остатка | `wui_stretch(c, доля)` | поле до края, список на всю высоту

В `wui_size` и `wui_min_size` ноль означает «как получится»: `wui_size(label, 90, 0)` задаёт только ширину, высота остаётся по тексту. Размеры — в точках, как и всё в WUI.

Заданный размер сильнее содержимого: если текст не влезает в 90 точек, надпись перенесёт его на вторую строку, а кнопка обрежет. Поэтому ширину задают тем элементам, содержимое которых известно, а для текста от пользователя или из перевода лучше `wui_min_size` — не уже стольких-то точек, а если надо, шире.

## Доли остатка

`wui_stretch(c, доля)` говорит: этот элемент получает часть того, что осталось в родителе после всех остальных. В столбце это доля высоты, в строке — ширины. Родитель сначала отдаёт место детям без доли — каждому по содержимому или по заданному размеру, затем промежутки, а остаток делит между долевыми детьми пропорционально числам.

```
WuiControl *body = wui_row(wui_content(win));
wui_stretch(body, 1);                   // строка — на всю высоту окна
WuiControl *left = wui_card(body, "Список");
wui_stretch(left, 1);                   // одна доля ширины
WuiControl *right = wui_card(body, "Подробно");
wui_stretch(right, 2);                  // две доли: вдвое шире левой
```

Число доли важно только по отношению к соседям: `1` и `2` дают то же, что `10` и `20`. Ноль снимает долю — элемент снова по содержимому.

Пустое место `wui_spacer(родитель)` — элемент без вида с долей 1. Он ничего не рисует, а только забирает остаток: в строке перед кнопками прижимает их вправо, между двумя кнопками разводит их по краям, два пустых места по бокам надписи ставят её посередине.

! Доля работает только там, где есть остаток. В прокрутке высота не ограничена, и долевой ребёнок получает размер по содержимому; в переносе доли не действуют вовсе. Если элемент с `wui_stretch` не растягивается — проверьте, растянут ли его родитель: строка в столбце содержимого сама по высоте по содержимому, и ей тоже нужен `wui_stretch(row, 1)`.

## Поперёк: выравнивание

Доля и размер говорят о направлении родителя: высоте в столбце, ширине в строке. Поперёк — ширину в столбце, высоту в строке — задаёт выравнивание `wui_align(c, как)`.

:= Значение | Что делает поперёк родителя
: `WUI_ALIGN_STRETCH` | растягивает на всю ширину столбца или высоту строки
: `WUI_ALIGN_START` | ставит по своему размеру к левому краю столбца или к верху строки
: `WUI_ALIGN_CENTER` | по своему размеру посередине
: `WUI_ALIGN_END` | по своему размеру к правому краю столбца или к низу строки

У каждого вида элементов своё выравнивание по умолчанию, подобранное так, чтобы чаще всего ничего не менять.

:= Элемент | В столбце | В строке
: Надпись с переносом (все виды, кроме BIG и SECTION) | во всю ширину | посередине по высоте
: Надпись BIG и SECTION | к левому краю | посередине
: Кнопка | к левому краю, своей ширины | посередине
: Флажок, переключатель, кнопка выбора | к левому краю | посередине
: Раскрывающийся список | во всю ширину | посередине
: Поле, ползунок, полоса хода, список, холст | во всю ширину | во всю высоту строки
: Строка, столбец, карточка, вкладки | во всю ширину | во всю высоту строки
: Значок, выбор темы | посередине | посередине

Например, раскрывающийся список в карточке по умолчанию тянется во всю её ширину; чтобы он был по самому длинному пункту, пишут `wui_align(combo, WUI_ALIGN_START)`. Строка кнопок, прижатая вправо без пустого места, — `wui_align(buttons, WUI_ALIGN_END)`: строка станет по своему содержимому и встанет к правому краю.

Заданный размер сильнее растяжения: элемент с `wui_size(c, 300, 0)` в столбце будет шириной 300 точек у левого края, даже если выравнивание «во всю ширину».

## Поля и промежутки

Три функции управляют пустотой вокруг и внутри элементов.

:= Функция | Где пустота
: `wui_margin(c, слева, сверху, справа, снизу)` | снаружи элемента: отодвигает его от соседей и краёв родителя
: `wui_padding(c, слева, сверху, справа, снизу)` | внутри контейнера: между его краем и детьми
: `wui_gap(c, точки)` | внутри контейнера: между соседними детьми

Внешнее поле принадлежит элементу и действует в любом родителе: `wui_margin(note, 6, 0, 6, 4)` отодвигает надпись от боков. Промежуток — свойство контейнера, он одинаков между всеми его детьми. Если между двумя группами нужен больший разрыв, чем между элементами внутри группы, группы делают отдельными столбцами, а не правят поля каждого элемента.

У карточки внутренние поля по умолчанию задаёт тема: в «Стекле» они одни, в «Пергаменте» другие. `wui_padding` ставит карточке свои поля вместо полей темы — например, `wui_padding(card, 28, 24, 28, 24)` для просторной карточки-приветствия; заголовок карточки остаётся над содержимым, внутри новых полей. Со своими полями карточка уже не следует теме, поэтому их задают только тогда, когда отступ темы действительно не подходит.

Поля самого окна — расстояние от края окна до содержимого — тоже задаёт тема, и у разных тем они разные. Добавить к ним своё можно внешним полем столбца содержимого: `wui_margin(wui_content(win), 0, 0, 0, 8)` оставит внизу окна ещё 8 точек.

## Карточка

`wui_card(родитель, заголовок)` — панель темы: фон, тень, блик и рамка, как у панелей ThemeLibrary. Внутри — столбец с промежутком 10 точек. Заголовок рисуется сверху шрифтом заголовков карточек; если передать ноль, заголовка нет и карточка — просто панель. Карточки — главное средство показать, что элементы связаны: «Данные», «Итог», «Настройки печати».

Карточку можно положить куда угодно: в столбец, в строку (тогда это колонка-панель), в перенос (плитка). Карточки в карточках выглядят тяжело; внутри карточки группы разделяют чертой `wui_separator` или подписью `WUI_LABEL_SECTION`.

## Перенос

Перенос (`wui_wrap`) кладёт детей слева направо, как строка, но когда очередной не помещается по ширине, начинает новую строку — как слова в абзаце. Это раскладка для плиток, ряда кнопок, набора флажков: в широком окне их больше в строке, в узком — меньше. Промежуток у переноса 12 точек и по горизонтали, и между строками.

Каждый ребёнок переноса — своего размера. Чтобы плитки выстроились ровной сеткой, им задают одинаковую ширину: `wui_size` или `wui_min_size`.

```
#include <wui.h>
#include <stdio.h>

int main(void)
{
    static const char *months[12] = { "Январь", "Февраль", "Март", "Апрель", "Май", "Июнь",
                                      "Июль", "Август", "Сентябрь", "Октябрь", "Ноябрь", "Декабрь" };
    static const int days[12] = { 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31 };

    WuiControl *win = wui_window("Месяцы", 780, 520, "Months");
    WuiControl *page = wui_content(win);
    wui_label(page, "Дней в месяце", WUI_LABEL_H1);

    WuiControl *scroll = wui_scroll(page);          // всё, что в нём, прокручивается
    WuiControl *tiles = wui_wrap(scroll);           // плитки — строками с переносом
    for (int i = 0; i < 12; i++) {
        char number[8];
        snprintf(number, sizeof number, "%d", days[i]);
        WuiControl *tile = wui_card(tiles, 0);
        wui_min_size(tile, 160, 0);
        wui_gap(tile, 2);
        wui_label(tile, months[i], WUI_LABEL_DIM);
        wui_label(tile, number, WUI_LABEL_BIG);
    }
    wui_label(page, "В високосный год в феврале 29 дней.", WUI_LABEL_DIM);
    return wui_run();
}
```

Каждая плитка — карточка без заголовка шириной не меньше 160 точек, в ней две надписи: бледное название и крупное число. Надпись `WUI_LABEL_BIG` — крупный тонкий шрифт цветом акцента со свечением; она сделана для таких показателей.

Строки в цикле живут в массиве `number` на стеке, и это не ошибка: `wui_label` копирует текст к себе, так что после вызова массив можно менять или терять. Так ведут себя все функции WUI, которые принимают строки.

## Прокрутка

Если содержимое выше окна, нижние элементы просто не поместятся: столбец не умеет показывать больше, чем у него места. Для этого есть прокрутка — `wui_scroll(родитель)`. Это столбец, у которого высота содержимого может быть любой: когда оно не влезает, справа появляется полоса прокрутки, а колесо мыши сдвигает содержимое.

В примере выше прокрутка стоит между заголовком и нижней надписью. У прокрутки по умолчанию доля 1, поэтому она забрала всю высоту между ними; заголовок и надпись остались на местах, а плитки прокручиваются. В узком окне это видно сразу: плиток в строке меньше, строк больше, и появляется полоса.

@ 14-плитки-узко.png | То же окно шириной 520 точек: по две плитки в строке и полоса прокрутки справа

Полосу можно тащить мышью, щелчок по пустому месту полосы листает на страницу, колесо сдвигает на 48 точек за щелчок. Прокрутка только вертикальная: по ширине содержимое всегда сжимается до окна, а длинный текст переносится. Если прокруток несколько — например, боковое меню и страница, — колесо крутит ту, над которой мышь.

Прокрутку обычно делают одну на страницу и кладут в неё всё, что может вырасти: список карточек, длинную форму, отчёт. Заголовок страницы и кнопки действий оставляют снаружи, чтобы они всегда были видны.

## Черта, пустое место, скрытые элементы

`wui_separator(родитель)` — тонкая черта цвета разделителей темы с полями по 4 точки сверху и снизу; в столбце она горизонтальная во всю ширину. Ею разделяют группы внутри карточки.

`wui_spacer(родитель)` уже встречался: пустое место с долей 1. Двумя пустыми местами по бокам ставят элемент посередине строки, одним — прижимают к краю.

Скрытый элемент (`wui_show(c, 0)`) не просто невидим — он не занимает места, и соседи сдвигаются, как будто его нет. `wui_show(c, 1)` возвращает его. На этом держатся страницы: несколько столбцов в одном родителе, из которых показан один, — так устроены боковое меню в главе 16 и вкладки в главе 15.

## Когда места не хватает

Доли делят только лишнее место. Если окно сжали так, что даже элементам без доли не хватает места, WUI их не уменьшает (подстраиваются только надписи, перенося текст): строка не переносит кнопки на вторую строку, столбец не прячет нижние элементы — они уходят за край контейнера и обрезаются краем окна. Долевые элементы в это время получают ноль: поле с `wui_stretch` сжимается до пустой полоски.

Поэтому у каждого окна есть ширина и высота, меньше которых его раскладка теряет смысл. Их находят, сжимая окно в нескольких темах — шрифты тем разного размера, — и ставят `wui_window_min_size(win, ширина, высота)`: пользователь просто не сможет сделать окно меньше. Строку заголовка так беречь не нужно: уже значка, элементов `wui_titlebar` и кнопок окна WUI окно не сжимает сама, а название окна в тесноте прячет. Если окно должно оставаться полезным и узким, то, что не помещается по ширине, кладут в перенос, а по высоте — в прокрутку.

## Как найти ошибку в раскладке

Раскладка невидима: строки и столбцы ничего не рисуют, и если элемент встал не туда, непонятно, у кого какие границы. Простой способ — временно заменить подозрительный `wui_row` или `wui_column` на `wui_card(…, 0)`: карточка раскладывает детей так же, как столбец, но видна. Так сразу видно, растянут ли контейнер, где кончается строка и куда ушло место.

Частые причины, по которым раскладка выходит не такой, как задумано:

- элемент с `wui_stretch` не растягивается — у его родителя нет лишнего места: родителю тоже нужна доля;
- кнопки после длинной надписи в строке ушли за край — надпись забрала всю оставшуюся ширину; дайте ей долю (`wui_stretch(label, 1)`): тогда строка сначала отдаст место кнопкам, а надписи — остаток, и она перенесётся по нему;
- раскрывающийся список во всю ширину карточки — так он выравнивается по умолчанию, нужен `WUI_ALIGN_START`;
- нижние элементы обрезаны — содержимое выше окна, нужна прокрутка или меньший наименьший размер окна.

## Итог

Раскладку в WUI задают правилами, а не координатами. Столбец кладёт детей сверху вниз, строка — слева направо, перенос — строками, прокрутка — столбцом любой высоты, карточка — столбцом на панели темы. Размер элемента по умолчанию — по содержимому; `wui_size` задаёт его, `wui_min_size` ограничивает снизу, `wui_stretch` даёт долю того, что осталось, а пустое место `wui_spacer` забирает остаток, чтобы прижать соседей к краю.

Поперёк родителя элемент растягивается или встаёт к краю или середине по `wui_align`; у каждого вида разумное выравнивание по умолчанию. Пустоту снаружи элемента задаёт `wui_margin`, внутри контейнера — `wui_padding` и `wui_gap`. Всё пересчитывается само при изменении окна, темы и масштаба. Следующая глава — об элементах, которые кладутся в эти контейнеры, и о событиях, через которые программа узнаёт, что с ними сделали.
