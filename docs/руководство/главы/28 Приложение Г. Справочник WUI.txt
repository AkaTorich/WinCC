# Приложение Г. Справочник WUI
Все функции, типы и константы заголовка `wui.h` и список значков `wui_icons.h` — по группам, в порядке заголовка. Размеры — в точках DIP (1/96 дюйма; масштаб экрана WUI учитывает сама), тексты — строки UTF-8. Строки, которые принимают функции WUI, копируются, и после вызова их можно менять. Объяснения с примерами — в главах 13–17.

## Подключение и типы

:= Что | Значение
: `#include <wui.h>` | включает `windows.h` и `gdiplus.h`; строкой `#pragma comment(lib, "wui")` подключает исходники `lib\wui`, строкой `#pragma comment(linker, "/SUBSYSTEM:WINDOWS")` делает программу оконной
: `wcc --console файл.c` | программа на WUI с консолью рядом — для отладочной печати
: `WuiControl` | элемент; окно — тоже элемент. Программа держит только указатели `WuiControl *`
: `WuiHandler` | обработчик события: `void f(WuiControl *c, void *user)`
: `WuiPaint` | рисование холста: `void f(WuiControl *c, GpGraphics *g, float width, float height, void *user)`
: `WuiIconData` | значок: пути контура и заливки на сетке 24 × 24

## Окно

:= Функция | Что делает
: `WuiControl *wui_window(const char *title, int width, int height, const char *key)` | создаёт окно размером `width × height` точек без тени посреди монитора, где мышь; `key` — имя, под которым помнится тема, 0 — не помнить
: `WuiControl *wui_content(WuiControl *window)` | столбец содержимого под заголовком, промежуток 12
: `WuiControl *wui_titlebar(WuiControl *window)` | строка справа в заголовке перед кнопками окна, промежуток 8
: `void wui_window_subtitle(WuiControl *window, const char *text)` | бледный подзаголовок после названия
: `void wui_window_logo(WuiControl *window, const WuiIconData *icon)` | значок слева в заголовке
: `void wui_window_extend(WuiControl *window, int on)` | 1 — содержимое до самого верха, без плашки заголовка, название и значок не рисуются; кнопки окна и `wui_titlebar` — справа поверх
: `void wui_window_min_size(WuiControl *window, int width, int height)` | наименьший размер окна; по умолчанию 360 × 240; уже значка, `wui_titlebar` и кнопок окна окно не сжимается при любом пределе
: `void wui_window_close(WuiControl *window)` | закрыть окно
: `HWND wui_hwnd(WuiControl *window)` | окно Windows — для `SetTimer`, буфера обмена, диалогов
: `int wui_run(void)` | цикл сообщений, пока открыто хоть одно окно; возвращает код выхода
: `void wui_quit(int code)` | закрыть все окна; `wui_run` вернёт `code`

Название окна меняет `wui_text(window, "…")`, читает `wui_get_text(window)`. Окно тянется за заголовок и края, разворачивается в рабочую область своего монитора, у каждого монитора свой масштаб. Когда строка заголовка не помещается, первым прячется название окна с подзаголовком.

## Темы

:= Функция | Что делает
: `int wui_theme_count(void)` | число тем — 61
: `const char *wui_theme_id(int index)` | Id темы: `"Emerald"`; неверный номер — `""`
: `const char *wui_theme_name(int index)` | имя: `"Изумруд и золото"`
: `const char *wui_theme_group(int index)` | группа: `"Стекло"`
: `int wui_theme_current(void)` | номер текущей темы
: `void wui_theme_set(const char *id)` | сменить тему во всех окнах и записать в файл ключа; Id без учёта регистра; незнакомый Id — ничего
: `COLORREF wui_color(int which)` | цвет текущей темы для GDI
: `ARGB wui_argb(int which)` | цвет с прозрачностью `0xAARRGGBB` для GDI+

Выбор темы хранится в `%APPDATA%\ThemeLibrary\ключ.theme` — одна строка с Id, как у ThemeLibrary. Действует ключ первого окна, у которого он задан. Файл пишется только при смене темы. Таблица всех тем — в главе 16.

## Цвета темы

:= Константа | Номер | Цвет
: `WUI_TEXT` | 0 | основной текст
: `WUI_TEXT_DIM` | 1 | бледный текст
: `WUI_ACCENT` | 2 | акцент
: `WUI_ACCENT2` | 3 | второй акцент
: `WUI_SUCCESS` | 4 | «хорошо»
: `WUI_WARNING` | 5 | «внимание»
: `WUI_DANGER` | 6 | «плохо»
: `WUI_SURFACE` | 7 | поверхность панелей; в тёмных темах обычно белый

## Раскладка

:= Функция | Что делает
: `WuiControl *wui_column(WuiControl *parent)` | столбец: дети сверху вниз, промежуток 0
: `WuiControl *wui_row(WuiControl *parent)` | строка: дети слева направо, промежуток 10
: `WuiControl *wui_wrap(WuiControl *parent)` | перенос: слева направо, не влезло — новая строка; промежуток 12; доли не действуют
: `WuiControl *wui_scroll(WuiControl *parent)` | столбец с вертикальной прокруткой; доля 1
: `WuiControl *wui_card(WuiControl *parent, const char *title)` | панель темы, внутри столбец с промежутком 10; `title` может быть 0; внутренние поля задаёт тема, `wui_padding` — свои вместо них
: `WuiControl *wui_spacer(WuiControl *parent)` | пустое место с долей 1
: `WuiControl *wui_separator(WuiControl *parent)` | черта толщиной 1, поля 4 сверху и снизу
: `void wui_size(WuiControl *c, float width, float height)` | заданный размер; 0 — по содержимому
: `void wui_min_size(WuiControl *c, float width, float height)` | наименьший размер; 0 — без ограничения
: `void wui_stretch(WuiControl *c, float weight)` | доля остатка вдоль родителя; 0 — нет доли
: `void wui_margin(WuiControl *c, float left, float top, float right, float bottom)` | поле снаружи элемента
: `void wui_padding(WuiControl *c, float left, float top, float right, float bottom)` | поле внутри контейнера; у карточки — вместо полей темы
: `void wui_gap(WuiControl *c, float gap)` | промежуток между детьми контейнера
: `void wui_align(WuiControl *c, int align)` | выравнивание поперёк родителя

:= Константа | Поперёк родителя
: `WUI_ALIGN_STRETCH` | на всю ширину столбца или высоту строки
: `WUI_ALIGN_START` | своего размера, к левому краю или к верху
: `WUI_ALIGN_CENTER` | своего размера, посередине
: `WUI_ALIGN_END` | своего размера, к правому краю или к низу

Выравнивание по умолчанию: надписи с переносом, поля, ползунок, полоса хода, списки, холст, вкладки, контейнеры — `STRETCH`; кнопки, флажки, переключатели, кнопки выбора, надписи `BIG` и `SECTION` — `START`; значок и выбор темы — `CENTER`; в строке надписи, кнопки, флажки и раскрывающийся список — `CENTER`. Заданный размер сильнее `STRETCH`.

## Общее для всех элементов

:= Функция | Что делает
: `void wui_text(WuiControl *c, const char *text)` | новый текст: надписи, кнопки, подписи, содержимого поля, названия окна
: `const char *wui_get_text(WuiControl *c)` | текст в UTF-8; у поля строка годна, пока поле не поправили (при том же тексте повторный вызов отдаёт ту же строку), у списков — пока не очищены пункты
: `void wui_value(WuiControl *c, double value)` | значение: флажок 0 или 1, ползунок (обрезается по пределам), полоса, выбранный пункт (список прокручивается к выбранной строке), вкладка, выбор кнопки выбора и пункта меню
: `double wui_get_value(WuiControl *c)` | значение
: `void wui_enable(WuiControl *c, int on)` | 0 — выключить: полупрозрачный, без мыши и клавиатуры, Tab пропускает; у контейнера выключает и всё, что внутри
: `void wui_show(WuiControl *c, int on)` | 0 — спрятать вместе с местом
: `void wui_on_click(WuiControl *c, WuiHandler fn, void *user)` | обработчик щелчка; 0 — снять
: `void wui_on_change(WuiControl *c, WuiHandler fn, void *user)` | обработчик изменения; 0 — снять
: `void wui_focus(WuiControl *c)` | фокус клавиатуры на элемент; можно звать и до `wui_run`
: `void wui_redraw(WuiControl *c)` | перерисовать — нужно холсту после правки его данных
: `void wui_set_data(WuiControl *c, void *data)` | прицепить к элементу свой указатель
: `void *wui_get_data(WuiControl *c)` | получить его
: `WuiControl *wui_window_of(WuiControl *c)` | окно, в котором лежит элемент

События вызывает только пользователь; `wui_value` и `wui_text` из программы обработчиков не зовут.

:= Элемент | Значение и текст | Щелчок | Изменение
: Надпись | текст | — | —
: Кнопка | текст | мышь, пробел, Enter | —
: Поле, поле пароля | текст — введённое | Enter | каждая правка
: Флажок, переключатель | 0 или 1; текст — подпись | при переключении, после изменения | при переключении
: Кнопка выбора | 1 у выбранной; текст — подпись | при выборе и щелчке по выбранной | —
: Ползунок | от `min` до `max`, дробное | — | при движении мышью и стрелками; стрелка на краю — нет
: Полоса хода | заданное число | — | —
: Раскрывающийся список | номер пункта, −1 — пуст; текст пункта | — | выбран другой пункт
: Список | номер строки, −1 — нет выбора; текст строки | двойной щелчок, Enter | выбрана строка
: Вкладки | номер открытой страницы | — | открыта другая
: Пункт бокового меню | 1 у выбранного; текст | при выборе | —
: Выбор темы | номер темы; имя темы | — | выбрана другая тема
: Холст | — | кнопку мыши отпустили над холстом | —

: Вкладки | стрелки влево и вправо
: Сообщение | Enter, пробел — первая кнопка; Esc — ответ 0

## Переменные окружения

WUI читает их при создании первого окна программы.

:= Переменная | Что делает
: `WUI_SNAPSHOT=файл.png` | сохранить первое окно картинкой после первой отрисовки и закрыть программу; окно на экране не показывается
: `WUI_SNAPSHOT_WAIT=1` | вместе с `WUI_SNAPSHOT`: окно показывается и живёт, снимок `файл-N.png` — по сообщению окну `WM_APP+3` с `N` в `wParam`
: `WUI_THEME=Id` | тема вместо запомненной; файл ключа не меняется
: `WUI_SIZE=ширина,высота` | размер окна в точках вместо заданного
: `WUI_SCALE=число` | масштаб экрана вместо настоящего: `2` — как при 200 %
