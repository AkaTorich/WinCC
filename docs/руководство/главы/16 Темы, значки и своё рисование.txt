# Темы, значки и своё рисование
Тема в WUI — не цвет кнопок, а весь облик окна: фон из градиента, бумаги, камня или металла, пятна света и звёзды, узоры, рамка по краю, шрифты заголовков и текста, тени, свечение, скругления. Эта глава перечисляет все шестьдесят одну тему и показывает, как программа работает с ними сама: выбирает тему, берёт её цвета для своего рисования на холсте, ставит значки. Здесь же — большие окна с боковым меню и содержимым до самого верха, сообщения и несколько окон в одной программе.

## Шестьдесят одна тема

Темы WUI — все темы ThemeLibrary, кроме цветов пергамента: в ThemeLibrary их двенадцать, в WUI оставлен один, «Пергамент — гранат». Темы разбиты на одиннадцать групп, и в списке выбора они идут по группам.

У каждой темы три имени. Id — латинское, по нему тему выбирает программа и под ним тема запоминается в файле ключа. Имя — русское, его видит пользователь в списке. Группа — раздел списка. Все три даёт сама библиотека:

```
#include <wui.h>
#include <stdio.h>
#pragma comment(linker, "/SUBSYSTEM:CONSOLE")   // эта программа печатает, окно ей не нужно

int main(void)
{
    for (int i = 0; i < wui_theme_count(); i++)
        printf("%-14s %-26s %s\n", wui_theme_id(i), wui_theme_name(i), wui_theme_group(i));
    return 0;
}
```

## Тема из программы

Обычно тему выбирает пользователь списком `wui_theme_picker`, но программа может и сама.

:= Функция | Что делает
: `wui_theme_count()` | число тем — 61
: `wui_theme_id(i)`, `wui_theme_name(i)`, `wui_theme_group(i)` | Id, имя и группа темы номер `i`; для неверного номера — пустая строка
: `wui_theme_current()` | номер текущей темы
: `wui_theme_set("Id")` | сменить тему во всех окнах и запомнить под ключом программы

`wui_theme_set` ищет тему по Id без учёта регистра; незнакомый Id она молча пропускает, и тема остаётся прежней. Если у программы есть ключ, выбор записывается в файл, как при выборе списком. Так делают выбор без списка — например, две кнопки выбора «Светлая» и «Тёмная» с `wui_theme_set("Marble")` и `wui_theme_set("Obsidian")` в обработчиках.

Темой первого запуска всегда остаётся «Изумруд и золото». Если программе нужна другая, её ставят при запуске, но только когда пользователь ещё ничего не выбирал — иначе программа будет каждый раз перебивать его выбор. Проще всего проверить, есть ли файл `%APPDATA%\ThemeLibrary\ключ.theme`: нет — поставить свою тему.

Когда пользователь выбирает в списке другую тему, список зовёт свой обработчик изменения; номер новой темы даёт `wui_theme_current()`. Если выбрали ту же тему, что уже стоит, события нет, а `wui_theme_set` из программы, как и любая программная правка, обработчиков не зовёт. Обычно это событие и не нужно: элементы и холсты перерисовываются в новой теме сами, а цвета для своего рисования читаются в момент рисования. Нужно оно тогда, когда от темы зависит что-то ещё — надпись с её именем, картинка, которую программа готовит заранее:

```
static void theme_changed(WuiControl *picker, void *user)
{
    (void)picker; (void)user;
    wui_text(g_status, wui_theme_name(wui_theme_current()));
}

// в main, после создания окна:
wui_on_change(wui_theme_picker(wui_titlebar(win)), theme_changed, 0);
```

Текущую тему в любой момент дают `wui_get_value(picker)` — её номер — и `wui_theme_current()`.

## Цвета темы

Для своего рисования тема даёт восемь цветов.

:= Константа | Что это
: `WUI_TEXT` | цвет основного текста
: `WUI_TEXT_DIM` | бледный текст, подписи, деления шкал
: `WUI_ACCENT` | главный цвет темы — акцент
: `WUI_ACCENT2` | второй акцент
: `WUI_SUCCESS` | «хорошо»: готово, в норме
: `WUI_WARNING` | «внимание»
: `WUI_DANGER` | «плохо»: ошибка, удаление, превышение
: `WUI_SURFACE` | цвет поверхностей; в тёмных темах обычно белый, его кладут с малой непрозрачностью

`wui_argb(N)` возвращает цвет в виде `0xAARRGGBB` — так его берёт GDI+. `wui_color(N)` возвращает тот же цвет как `COLORREF` для GDI (`RGB(r, g, b)`, без прозрачности). Цвет читается в момент вызова, поэтому рисование, которое берёт цвета внутри себя, само подстраивается под новую тему.

Цвета подобраны к теме: текст читается на её фоне, акцент виден на поверхности. Рисунок, сделанный только из цветов темы, выглядит своим в любой из шестидесяти одной — это видно на часах ниже.

## Холст: своё рисование

Холст — элемент, который рисует сама программа. `wui_canvas(родитель, функция, данные)` создаёт его и запоминает функцию рисования:

```
void paint(WuiControl *c, GpGraphics *g, float width, float height, void *user);
```

WUI зовёт её при каждой перерисовке холста — когда окно показывается, меняет размер, тему или масштаб. `g` — уже готовая поверхность GDI+: начало координат — левый верхний угол холста, единица — точка, масштаб экрана учтён, сглаживание включено, а всё, что выходит за края холста, обрезается. `width` и `height` — размер холста в точках. Рисовать можно любыми функциями GDI+ из `gdiplus.h`: линии, фигуры, градиенты, текст, картинки. Подробно GDI+ разобран в главе 12; здесь важно только то, что `g` создавать и освобождать не нужно — его даёт и забирает WUI.

Размер холста по умолчанию — 100 × 100 точек, в столбце он растягивается по ширине. Обычно ему задают высоту `wui_size(canvas, 0, 300)` или долю `wui_stretch(canvas, 1)`. Если то, что рисует холст, изменилось, его просят перерисоваться: `wui_redraw(canvas)`. Это дёшево: WUI перерисует только место холста и только тогда, когда до этого дойдёт цикл сообщений, сколько бы раз ни позвали `wui_redraw`.

Холст отвечает и на щелчок: `wui_on_click(canvas, …)` вызывается, когда кнопку мыши отпустили над холстом. Координат щелчка обработчик не получает: холст в WUI — место для показа, а не для рисования мышью.

Вот часы, которые рисуются только цветами темы. Время идёт само: раз в секунду таймер Windows перерисовывает холст.

```
#include <wui.h>
#include <math.h>
#include <stdio.h>

static WuiControl *g_face, *g_date;

// стрелка от центра под углом: доля круга 0…1, длина в долях радиуса
static void hand(GpGraphics *g, float cx, float cy, float r, double turn, float len, float width, ARGB color)
{
    double a = turn * 2 * 3.14159265358979 - 3.14159265358979 / 2;
    GpPen *pen;
    GdipCreatePen1(color, width, UnitPixel, &pen);
    GdipSetPenLineCap197819(pen, LineCapRound, LineCapRound, 0);
    GdipDrawLine(g, pen, cx, cy, cx + (float)cos(a) * r * len, cy + (float)sin(a) * r * len);
    GdipDeletePen(pen);
}

static void paint_face(WuiControl *c, GpGraphics *g, float w, float h, void *user)
{
    (void)c; (void)user;
    SYSTEMTIME t;
    GetLocalTime(&t);
    float cx = w / 2, cy = h / 2, r = (w < h ? w : h) / 2 - 10;

    GpSolidFill *fill;                                  // циферблат: цвет поверхности темы, полупрозрачный
    GdipCreateSolidFill((wui_argb(WUI_SURFACE) & 0x00FFFFFF) | 0x30000000, &fill);
    GdipFillEllipse(g, fill, cx - r, cy - r, 2 * r, 2 * r);
    GdipDeleteBrush(fill);
    GpPen *ring;                                        // ободок — цвет акцента
    GdipCreatePen1(wui_argb(WUI_ACCENT), 2, UnitPixel, &ring);
    GdipDrawEllipse(g, ring, cx - r, cy - r, 2 * r, 2 * r);
    GdipDeletePen(ring);
    for (int i = 0; i < 60; i++) {                      // деления: часовые — длиннее и ярче
        double a = i * 2 * 3.14159265358979 / 60;
        float inner = i % 5 ? 0.92f : 0.82f;
        GpPen *pen;
        GdipCreatePen1(wui_argb(i % 5 ? WUI_TEXT_DIM : WUI_ACCENT), i % 5 ? 1.0f : 2.5f, UnitPixel, &pen);
        GdipDrawLine(g, pen, cx + (float)cos(a) * r * inner, cy + (float)sin(a) * r * inner,
                     cx + (float)cos(a) * r * 0.98f, cy + (float)sin(a) * r * 0.98f);
        GdipDeletePen(pen);
    }
    double sec = t.wSecond + t.wMilliseconds / 1000.0;
    hand(g, cx, cy, r, (t.wHour % 12 + t.wMinute / 60.0) / 12, 0.5f, 5, wui_argb(WUI_TEXT));
    hand(g, cx, cy, r, (t.wMinute + sec / 60) / 60, 0.75f, 3, wui_argb(WUI_TEXT));
    hand(g, cx, cy, r, sec / 60, 0.85f, 1.5f, wui_argb(WUI_DANGER));
}

// таймер Windows: раз в секунду — перерисовать холст и дату
static void CALLBACK tick(HWND hwnd, UINT msg, UINT_PTR id, DWORD time)
{
    (void)hwnd; (void)msg; (void)id; (void)time;
    static const char *days[] = { "воскресенье", "понедельник", "вторник", "среда", "четверг", "пятница", "суббота" };
    SYSTEMTIME t;
    char line[80];
    GetLocalTime(&t);
    snprintf(line, sizeof line, "%02d.%02d.%d, %s", t.wDay, t.wMonth, t.wYear, days[t.wDayOfWeek]);
    wui_text(g_date, line);
    wui_redraw(g_face);
}

int main(void)
{
    WuiControl *win = wui_window("Часы", 520, 600, "Clock");
    wui_window_logo(win, WUI_ICON_CLOCK);
    wui_theme_picker(wui_titlebar(win));
    WuiControl *page = wui_content(win);

    g_face = wui_canvas(page, paint_face, 0);
    wui_stretch(g_face, 1);                             // холст — на всю высоту окна
    g_date = wui_label(page, "", WUI_LABEL_H2);
    wui_align(g_date, WUI_ALIGN_CENTER);

    tick(0, 0, 0, 0);
    SetTimer(wui_hwnd(win), 1000, 1000, tick);
    return wui_run();
}
```

@ 16-часы-пергамент.png | Часы в теме «Пергамент — гранат»: акцент гранатовый, текст тёмно-коричневый
@ 16-часы-сталь.png | Те же часы в теме «Сталь и ЖК» из группы «Приборы»
@ 16-часы-терминал.png | В теме «Терминал — зелёный» из группы «Экраны»
@ 16-часы-египет.png | В теме «Египет»: фактура папируса и рамка из знаков

Функция `paint_face` не знает, какая тема стоит: циферблат — цвет поверхности с непрозрачностью 0x30 из 0xFF, ободок и часовые деления — акцент, минутные деления — бледный текст, часовая и минутная стрелки — цвет текста, секундная — «опасный» цвет. Из восьми цветов получаются часы, родные для каждой темы. Выражение `(цвет & 0x00FFFFFF) | 0x30000000` меняет у цвета `0xAARRGGBB` только непрозрачность.

Таймер — обычная функция Windows `SetTimer`. Ей нужно окно, его даёт `wui_hwnd(win)`, и функция обратного вызова `tick`, которую цикл сообщений `wui_run` будет вызывать раз в 1000 мс. Номер таймера 1000 выбран большим, чтобы не совпасть с таймерами самой WUI (у неё номера 1–3). `tick` обновляет надпись с датой и просит перерисовать холст. Так же к WUI подключается всё, что умеет Windows: буфер обмена, диалог выбора файла (`GetOpenFileNameW` с окном-хозяином `wui_hwnd(win)`), звук, реестр.

Наименьший размер часам не задан, и за строку заголовка можно не беспокоиться. Значок, название, список тем шириной 230 точек и три кнопки окна занимают около пятисот точек. Если сузить окно, первым прячется название, а значок, список тем и кнопки окна остаются на местах; уже них WUI окно не сжимает, поэтому кнопки справа никогда не уходят за край. Циферблат при этом просто становится меньше: его радиус считается от ширины и высоты холста.

## Значки

В WUI есть 123 значка ThemeLibrary: «дом», «поиск», «сохранить», стрелки, файлы, папки, «настройки», графики, а также знаки — анх, гексаграмма, стихии, алхимические металлы, зодиак. Они нарисованы линиями на сетке 24 × 24 и красятся в цвет темы. Имена — `WUI_ICON_HOME`, `WUI_ICON_SEARCH` и так далее; полный список — в приложении Г. В программу попадают только те значки, которые она упоминает.

:= Где | Как
: Отдельный значок | `wui_icon(родитель, WUI_ICON_…, размер)` — цветом акцента, размер в точках
: На кнопке | `wui_button_icon(кнопка, WUI_ICON_…)` — 18 точек слева от текста, цветом текста кнопки
: В пункте бокового меню | `wui_nav_item(родитель, WUI_ICON_…, "текст")`
: В заголовке окна | `wui_window_logo(win, WUI_ICON_…)`
: На холсте | `wui_draw_icon(g, WUI_ICON_…, x, y, размер, цвет)` — любым цветом `ARGB`

Значок — это структура `WuiIconData` с двумя путями: контуром, который обводится пером, и заливкой. Путь — числа подряд: `0 x y` — начать фигуру в точке, `1 x y` — линия до точки, `2 x1 y1 x2 y2 x y` — кривая Безье, `3` — замкнуть фигуру. Координаты — на сетке 24 × 24. Так можно нарисовать и свой значок; WUI обращается с ним так же, как со своими.

```
#include <wui.h>

// свой значок на сетке 24×24: контур — домик-треугольник с дверью, заливка — круг-солнце
static const float house[] = { 0, 3, 21,  1, 12, 6,  1, 21, 21,  3,
                               0, 10, 21,  1, 10, 15,  1, 14, 15,  1, 14, 21 };
static const float sun[] = { 0, 17, 3,  2, 19.2f, 3, 21, 4.8f, 21, 7,  2, 21, 9.2f, 19.2f, 11, 17, 11,
```

## Боковое меню и содержимое до верха

Окно с несколькими разделами удобно делать боковым меню: панель слева, в ней пункты со значками, справа — страница выбранного раздела. В WUI это обычная строка из двух частей и три функции.

`wui_nav_item(родитель, значок, текст)` — пункт меню. Пункты с общим родителем образуют группу, как кнопки выбора: выбран всегда один, первый созданный — сразу. Щелчок выбирает пункт и вызывает его обработчик щелчка; `wui_value(item, 1)` выбирает пункт из программы без события. `wui_nav_section(родитель, "Текст")` — подпись группы пунктов мелкими заглавными. Страницы — несколько столбцов в одном родителе, из которых показан один; обработчик пункта показывает свою страницу и прячет остальные через `wui_show`.

`wui_window_extend(win, 1)` убирает плашку заголовка: содержимое окна начинается от самого верха, а кнопки окна и всё, что лежит в `wui_titlebar`, остаются справа поверх. Название и значок окна при этом не рисуются — их место занимает шапка боковой панели. Окно по-прежнему тянется за верхнюю полосу: там, где нет элементов, она работает как заголовок.

```
#include <wui.h>
#include <stdio.h>

enum { PAGES = 3 };
static WuiControl *g_pages[PAGES];

// ---- «Цвета»: восемь цветов темы на холсте ----

static void paint_colors(WuiControl *c, GpGraphics *g, float w, float h, void *user)
{
    (void)c; (void)h; (void)user;
    static const wchar_t *names[] = { L"WUI_TEXT", L"WUI_TEXT_DIM", L"WUI_ACCENT", L"WUI_ACCENT2",
                                      L"WUI_SUCCESS", L"WUI_WARNING", L"WUI_DANGER", L"WUI_SURFACE" };
    GpFontFamily *family;
    GpFont *font;
    GpSolidFill *ink;
    GdipCreateFontFamilyFromName(L"Consolas", NULL, &family);
    GdipCreateFont(family, 13, FontStyleRegular, UnitPixel, &font);
    GdipCreateSolidFill(wui_argb(WUI_TEXT), &ink);
    float cell = w / 4;
    for (int i = 0; i < 8; i++) {                   // номера цветов идут подряд: WUI_TEXT = 0 …
        float x = (i % 4) * cell, y = (i / 4) * 90.0f;
        GpSolidFill *fill;
        GdipCreateSolidFill(wui_argb(i), &fill);
        GdipFillRectangle(g, fill, x + 4, y, cell - 8, 50);
        GdipDeleteBrush(fill);
        RectF at = { x + 4, y + 56, cell - 8, 20 };
        GdipDrawString(g, names[i], -1, font, &at, NULL, ink);
    }
    GdipDeleteBrush(ink);
    GdipDeleteFont(font);
    GdipDeleteFontFamily(family);
}

static WuiControl *page_colors(WuiControl *parent)
{
    WuiControl *p = wui_column(parent);
    wui_gap(p, 12);
    wui_label(p, "Цвета темы", WUI_LABEL_H1);
    wui_label(p, "wui_argb — для GDI+, wui_color — для GDI. Смените тему: холст перерисуется сам.", WUI_LABEL_DIM);
    WuiControl *canvas = wui_canvas(wui_card(p, 0), paint_colors, 0);
    wui_size(canvas, 0, 170);
    return p;
}

// ---- «Сообщения»: всплывающая строка, вопрос, ещё окно ----

static void say(WuiControl *b, void *user)
{
    (void)user;
    wui_toast(wui_window_of(b), "Всплывающая строка гаснет сама через две-три секунды");
}

static void ask(WuiControl *b, void *user)
{
    (void)user;
    int yes = wui_message(wui_window_of(b), "Вопрос", "Сохранить изменения перед выходом?", WUI_MSG_YES_NO);
    wui_toast(wui_window_of(b), yes ? "Ответ: да" : "Ответ: нет");
}

static void another_window(WuiControl *b, void *user)
{
    (void)b; (void)user;
    static int n;
    char title[40];
    snprintf(title, sizeof title, "Окно № %d", ++n);
    WuiControl *w = wui_window(title, 420, 220, 0);
    wui_label(wui_content(w), "Тема у всех окон одна: смените её в главном окне.", WUI_LABEL_BODY);
}

static WuiControl *page_messages(WuiControl *parent)
{
    WuiControl *p = wui_column(parent);
    wui_gap(p, 12);
    wui_label(p, "Сообщения и окна", WUI_LABEL_H1);
    WuiControl *row = wui_wrap(p);
    wui_on_click(wui_button(row, "Всплывающая строка", WUI_BUTTON_NORMAL), say, 0);
    wui_on_click(wui_button(row, "Вопрос", WUI_BUTTON_ACCENT), ask, 0);
    wui_on_click(wui_button(row, "Ещё окно", WUI_BUTTON_NORMAL), another_window, 0);
    return p;
}

// ---- «О программе» ----

static WuiControl *page_about(WuiControl *parent)
{
    WuiControl *p = wui_column(parent);
    wui_gap(p, 12);
    wui_label(p, "О программе", WUI_LABEL_H1);
    wui_label(p, "Витрина показывает цвета текущей темы, всплывающую строку, сообщение с вопросом "
                 "и второе окно. Тему выбирают в заголовке; выбор запоминается.", WUI_LABEL_BODY);
    return p;
}

// ---- боковое меню ----

static void open_page(WuiControl *item, void *user)
{
    (void)item;
    for (int i = 0; i < PAGES; i++) wui_show(g_pages[i], i == (int)(INT_PTR)user);
}

int main(void)
{
    WuiControl *win = wui_window("Витрина темы", 900, 540, "ThemeShowcase");
    wui_window_extend(win, 1);                          // содержимое — до самого верха окна
    wui_theme_picker(wui_titlebar(win));

    WuiControl *body = wui_row(wui_content(win));
    wui_stretch(body, 1);
    wui_gap(body, 16);

    WuiControl *side = wui_card(body, 0);               // боковая панель
    wui_size(side, 220, 0);
    wui_gap(side, 2);
    WuiControl *head = wui_row(side);
    wui_icon(head, WUI_ICON_LAYERS, 28);
    wui_label(head, "Витрина", WUI_LABEL_H2);
    wui_nav_section(side, "Тема");
    WuiControl *colors = wui_nav_item(side, WUI_ICON_SUN, "Цвета");
    wui_nav_section(side, "Окна");
    WuiControl *messages = wui_nav_item(side, WUI_ICON_CHAT, "Сообщения");
    WuiControl *about = wui_nav_item(side, WUI_ICON_INFO, "О программе");
    wui_on_click(colors, open_page, (void *)0);
    wui_on_click(messages, open_page, (void *)1);
    wui_on_click(about, open_page, (void *)2);

    WuiControl *pages = wui_column(body);               // страницы: видна одна
    wui_stretch(pages, 1);
    wui_margin(pages, 0, 52, 0, 0);                     // ниже строки заголовка
    g_pages[0] = page_colors(pages);
    g_pages[1] = page_messages(pages);
    g_pages[2] = page_about(pages);
    open_page(0, (void *)0);
    return wui_run();
}
```

@ 16-витрина.png | Боковое меню, содержимое до верха окна и цвета темы на холсте

Страницам дано поле сверху в 52 точки — `wui_margin(pages, 0, 52, 0, 0)`: при содержимом до верха справа наверху лежат выбор темы и кнопки окна, и страница не должна под них заходить. Боковая панель начинается от самого верха.

Номер страницы передан пункту меню данными обработчика — `(void *)1`, а обратно получен как `(int)(INT_PTR)user`. Это обычный способ отдать обработчику небольшое число. `INT_PTR` — целое размером с указатель; приведение через него не теряет битов.

В `paint_colors` номера цветов перебираются циклом: константы от `WUI_TEXT` до `WUI_SURFACE` идут подряд с нуля, поэтому `wui_argb(i)` при `i` от 0 до 7 даёт все восемь.

## Всплывающая строка и сообщение

`wui_toast(win, "текст")` показывает строку внизу окна на две-три секунды: «Сохранено», «Скопировано», «Сначала впишите имя». Она ничего не ждёт от пользователя и ничего не останавливает. Новая строка заменяет прежнюю.

`wui_message(win, "заголовок", "текст", кнопки)` — сообщение в оформлении темы, которое ждёт ответа. Кнопки — `WUI_MSG_OK` («ОК»), `WUI_MSG_OK_CANCEL` («ОК» и «Отмена»), `WUI_MSG_YES_NO` («Да» и «Нет»). Функция возвращает 1, если нажали «ОК» или «Да», и 0, если «Отмена», «Нет», Esc или крестик. Сообщение встаёт посреди окна-хозяина, а хозяин на это время выключен — щёлкать в нём нельзя. Функция не возвращается, пока сообщение открыто, поэтому её пишут прямо в условии:

```
if (!wui_message(win, "Удаление", "Удалить запись?", WUI_MSG_YES_NO)) return;
```

Высота сообщения подбирается по тексту. Первая кнопка получает фокус: Enter и пробел нажимают её.

## Несколько окон

Второе окно создаётся так же, как первое, — `wui_window`, и сразу живёт само: у него свой заголовок, свои элементы и обработчики, его можно закрыть, не трогая остальные. Создавать окна можно и до `wui_run`, и из обработчика — как кнопка «Ещё окно» в витрине. Тема у всех окон одна: смена в любом окне перекрашивает все.

Программа заканчивается, когда закрыто последнее окно. Это значит, что, закрыв главное окно, пользователь оставит открытыми второстепенные, и программа будет жить, пока не закроют и их. Если окна подчинённые и должны закрываться вместе с главным, программа закрывает их сама — `wui_window_close` для каждого — или завершается целиком через `wui_quit`.

## Снимок окна без экрана

Вид окна можно проверять без экрана и мыши — например, командным файлом, который после сборки сохраняет картинки окна в нескольких темах. Это делают переменные окружения, которые WUI читает при создании первого окна.

:= Переменная | Что делает
: `WUI_SNAPSHOT=файл.png` | первое окно после первой отрисовки сохраняется картинкой, программа закрывается; на экране окно не появляется
: `WUI_THEME=Id` | тема вместо запомненной; файл ключа не меняется
: `WUI_SIZE=ширина,высота` | размер окна в точках вместо заданного в программе
: `WUI_SCALE=2` | масштаб экрана: 2 — снимок вдвое чётче, как при масштабе 200 %

```
set WUI_SNAPSHOT=часы-сталь.png
set WUI_THEME=Steel
set WUI_SCALE=2
clock.exe
```

Снимок захватывает первое окно программы целиком — с тенью и прозрачными углами. Раскрытые списки и сообщения — отдельные окна, на снимок они не попадают.

## Итог

Темы WUI — шестьдесят одна тема ThemeLibrary в одиннадцати группах; у каждой есть Id для программы, имя для пользователя и группа для списка. Программа может читать их и ставить `wui_theme_set`, а для своего рисования берёт восемь цветов темы — `wui_argb` для GDI+ и `wui_color` для GDI — в момент рисования, и рисунок подстраивается под любую тему сам. Холст `wui_canvas` даёт программе готовую поверхность GDI+ в точках; перерисовать его просит `wui_redraw`, а `wui_hwnd` подключает таймеры и любые другие функции Windows.

Сто двадцать четыре значка ставятся на кнопки, пункты меню, в заголовок и на холст, а свой значок описывается теми же путями. Боковое меню — пункты `wui_nav_item` и страницы, которые показывает `wui_show`, а `wui_window_extend` отдаёт содержимому окно до самого верха. Следующая глава собирает всё это в одну программу — от замысла до готового exe.
