# Окна на Elements
Elements — вторая библиотека окон, которая входит в WinCC. Если WUI из части IV — это темы ThemeLibrary, перенесённые в Си, то Elements устроена как WPF: программа один раз строит дерево элементов, панели сами раскладывают своих детей, а поля, флажки и ползунки привязаны прямо к переменным программы. К этому добавлены вещи, которых нет в WUI: окна любой формы, эффекты поверх кадра, свои шрифты, анимации, таблица стилей в духе CSS. Эта глава показывает, как подключить Elements, построить окно, связать его с данными и где взять полный список функций.

## Подключение

Elements подключается одной строкой:

```
#include <elements.h>
```

Больше ничего не нужно. Заголовок сообщает wcc, что программе нужна библиотека `elements`, и компилятор сам соберёт её исходники из папки `lib\elements` рядом с `wcc.exe` вместе с программой — так же, как WUI и сеть. Функции, которые программа не зовёт, в `.exe` не попадают. Программа с `#include <elements.h>` получается оконной даже с `main`: консоль ей не нужна.

Готовая программа на Elements весит около 190–210 КБ и зависит только от DLL самой Windows; рисует она через GDI+, который есть в любой Windows.

:= Где | Что
: `include\elements.h` | весь интерфейс библиотеки, около двухсот строк с пояснениями
: `lib\elements\` | исходники библиотеки, собираются с каждой программой
: `examples\elements\demos\` | одиннадцать готовых примеров, у каждого свой проект
: `examples\elements\fonts\` | тридцать шрифтов Elements
: `examples\elements\DOCUMENTATION.md` | описание всех функций по разделам

## Элемент — это число

Всё, что видно в окне, — элементы: окно, панели, надписи, кнопки, поля. Элемент в программе — это число типа `el`; ноль значит «нет элемента». Каждая функция, которая создаёт элемент, первым параметром берёт родителя — панель, в которую он ляжет, и возвращает новый элемент:

```
el w = el_window("Заметки", 420, 300);   // окно 420 на 300 точек
el s = el_stack(w, 0);                    // столбец внутри окна
el b = el_button(s, "Сохранить");         // кнопка в столбце
```

Так строится дерево: окно, в нём панели, в панелях элементы. Строится оно один раз, в начале `main`, а потом `el_run()` отдаёт управление библиотеке: она принимает ввод, зовёт обработчики, раскладывает и рисует, пока окно не закроют. Когда ничего не происходит, окно спит и процессор не занимает.

Размеры задаются в точках экрана. На мониторе с масштабом 150 % окно 420 на 300 точек займёт 630 на 450 пикселей — пересчёт библиотека делает сама, а текст и линии остаются чёткими.

## Первое окно: кофейня

Окно заказа кофе: имя, напиток из списка, размер, крепость, сахар и кнопка, по которой внизу появляется заказ целиком.

```
#include <elements.h>
#include <stdio.h>

static const char *drinks[] = { "Эспрессо", "Капучино", "Латте", "Раф" };
static const char *sizes[] = { "маленький", "средний", "большой" };
static char name[40] = "Анна";
static int drink = 1, size = 1, sugar = 0, strength = 60;
static char summary[200] = "Соберите заказ и нажмите «Заказать».";

static void order(el e, void *arg)
{
    snprintf(summary, sizeof summary, "%s: %s %s%s, крепость %d %%",
             name[0] ? name : "Гость", sizes[size], drinks[drink],
             sugar ? ", с сахаром" : "", strength);
}

static el label(el grid, int row, const char *text)
{
    el t = el_text(grid, text);
    el_cell(t, row, 0, 1, 1);
    el_align(t, EL_START, EL_CENTER);
    el_margin(t, 0, 0, 16, 10);
    return t;
}

static el place(el grid, int row, el e)
{
    el_cell(e, row, 1, 1, 1);
    el_margin(e, 0, 0, 0, 10);
    return e;
}

int main(void)
{
    el w = el_window("Кофейня", 480, 400);
    el_theme_named("Янтарь");

    el g = el_grid(w, "Auto,*", "Auto,Auto,Auto,Auto,Auto,Auto,*");
    el_padding(g, 22, 20, 22, 20);

    label(g, 0, "Имя");
    place(g, 0, el_edit(g, name, sizeof name));

    label(g, 1, "Напиток");
    place(g, 1, el_combo(g, drinks, 4, &drink));

    label(g, 2, "Размер");
    el sizes_row = place(g, 2, el_stack(g, 1));
    el_gap(sizes_row, 14);
    for (int i = 0; i < 3; i++)
        el_radio(sizes_row, sizes[i], &size, i);

    label(g, 3, "Крепость");
    place(g, 3, el_slider(g, 20, 100, &strength));

    place(g, 4, el_check(g, "С сахаром", &sugar));

    el b = place(g, 5, el_button(g, "Заказать"));
    el_align(b, EL_START, EL_CENTER);
    el_size(b, 140, -1);
    el_on_click(b, order, 0);

    el out = el_text(g, "");
    el_cell(out, 6, 0, 1, 2);
    el_text_bind(out, summary);
    el_wrap_text(out, 1);
    el_font(out, 16, 1);

    el_run();
    return 0;
}
```

```
> wcc кофейня.c
Готово: кофейня.exe — оконная программа, 198144 байт, 2110 мс
```

## Элементы держат переменные программы

Главное, что отличает Elements, видно в строках вроде `el_edit(g, name, sizeof name)`. Поле ввода не хранит свой текст где-то внутри — оно пишет прямо в массив `name` программы. Список `el_combo` держит номер выбранного напитка в `drink`, ползунок — значение в `strength`, флажок — 0 или 1 в `sugar`. Переключатели `el_radio` с общей переменной `size` образуют группу: выбранный пишет в неё своё значение, 0, 1 или 2.

Поэтому обработчику кнопки не нужно ничего спрашивать у элементов: он читает обычные переменные. И наоборот: если программа сама поменяет `strength`, ползунок на следующем кадре встанет на новое место.

`el_text_bind(out, summary)` работает так же в другую сторону: надпись каждый кадр показывает то, что сейчас лежит в `summary`. Обработчик `order` просто переписывает строку, и заказ появляется в окне без единого вызова «обнови надпись».

:= Элемент | Создаётся | Переменная
: поле ввода | `el_edit(родитель, буфер, размер)` | массив `char`
: многострочное поле | `el_memo(родитель, буфер, размер)` | массив `char`
: поле пароля | `el_password(родитель, буфер, размер)` | массив `char`
: флажок | `el_check(родитель, текст, &v)` | `int`, 0 или 1
: переключатель | `el_radio(родитель, текст, &группа, значение)` | `int` группы
: раскрывающийся список | `el_combo(родитель, строки, число, &номер)` | `int`
: список | `el_listbox(родитель, строки, число, &номер)` | `int`
: ползунок | `el_slider(родитель, мин, макс, &v)` | `int`
: числовое поле | `el_number(родитель, мин, макс, шаг, &v)` | `int`
: полоса хода | `el_progress(родитель, макс, &v)` | `int`, только показывает

## События

`el_on_click(элемент, функция, аргумент)` вешает обработчик нажатия. Он срабатывает не только у кнопки: у пункта меню, у флажка, у поля ввода — по Enter, у надписи и картинки — по щелчку. `el_on_change` срабатывает, когда элемент изменил свою переменную: ползунок сдвинули, в поле напечатали, в списке выбрали другое.

Обработчик получает элемент, с которым это случилось, и тот указатель, что передали третьим параметром, — через него обработчику отдают свои данные. Вместо обработчиков можно спрашивать после кадра: `el_clicked(e)` и `el_changed(e)` отвечают, было ли нажатие или изменение. Это удобно в своём цикле вместо `el_run()`:

```
while (el_frame()) {
    if (el_clicked(save)) save_file();
}
```

## Раскладка

Панели сами расставляют детей; координаты программе нужны только на холсте `el_canvas`.

:= Панель | Как раскладывает
: `el_stack(родитель, 0)` | столбец сверху вниз; `1` вместо `0` — строка слева направо; промежуток — `el_gap`
: `el_grid(родитель, столбцы, строки)` | сетка; ячейка — `el_cell(e, строка, столбец, строк, столбцов)`
: `el_dock(родитель)` | дети прижимаются к сторонам (`el_dock_side`), последний занимает остаток
: `el_wrap(родитель)` | в строку, с переносом на следующую, когда места не хватает
: `el_scroll(родитель)` | один ребёнок, прокрутка колесом и ползунком
: `el_group(родитель, заголовок)` | рамка с заголовком вокруг содержимого
: `el_tabs(родитель)` и `el_tab(вкладки, заголовок)` | вкладки
: `el_border(родитель)` | рамка и фон вокруг одного ребёнка
: `el_canvas(родитель)` | дети стоят там, где велит `el_pos(e, x, y)`

Размеры столбцов и строк сетки пишутся строкой через запятую, как в WPF: `Auto` — по содержимому, `120` — ровно 120 точек, `*` — весь остаток, `2*` — вдвое больше остатка, чем у `*`. В «Кофейне» столбцы `"Auto,*"`: первый ровно по самой длинной подписи, второй — всё остальное, поэтому поля растягиваются вместе с окном. Последняя строка `*` забирает оставшуюся высоту под заказ.

Сам элемент управляет своим местом в ячейке: `el_size(e, ширина, высота)` (`-1` — по содержимому), `el_margin` — отступ снаружи, `el_padding` — внутри, `el_align(e, по горизонтали, по вертикали)` — `EL_STRETCH`, `EL_START`, `EL_CENTER`, `EL_END`. Кнопка «Заказать» стоит у левого края своей ячейки, шириной 140 точек; без `el_align` она растянулась бы на всю ячейку.

## Темы и стили

Шестнадцать тем вызываются по имени: `el_theme_named("Ночь")`, «День», «Аметист», «Изумруд», «Сапфир», «Рубин», «Янтарь», «Обсидиан», «Пергамент», «Океан», «Лес», «Сакура», «Графит», «Неон», «Золото», «Лёд». Тёмная или светлая основа без имени — `el_theme(1)` или `el_theme(0)`, цвет акцента — `el_accent(0x3B82F6)`.

Отдельный элемент оформляют строкой, похожей на CSS:

```
el_style(b, "background:#3B2A1A radius:10 padding:6 16 hover-background:#5A3E24 font-weight:bold");
```

А для всего окна сразу — таблицей стилей: `el_stylesheet("button{radius:10} .card{background:#fff;background-alpha:28} #title{font-size:28}")`, где правило выбирает элементы по виду (`button`), классу (`.card`, класс задаёт `el_class`) или имени (`#title`, имя задаёт `el_name`). Собственные настройки элемента сильнее правил таблицы.

## Окна любой формы

Окно Elements не обязано быть прямоугольником с рамкой Windows. `el_frameless(1)` убирает системную рамку — заголовок, кнопки и фон рисует программа, а `el_drag_region(e)` делает элемент «ручкой», за которую окно таскают. `el_window_round(16)` скругляет углы, `el_window_shape("ellipse")` делает окно овальным, `el_window_region` задаёт любой многоугольник, а форма `"pixels"` берёт контур из того, что нарисовано: окно получается ровно такой формы, как его рисунок.

@ 24-киберпанк.png | Пример cyberpunk.c: окно со скошенными углами, свои рамки кнопок и эффект расщепления цвета

Поверх готового кадра можно включить эффекты: `el_effect("scanlines", 30)` — строки развёртки, `"chromatic"` — расщепление цвета, `"bloom"` — свечение ярких мест, `"vignette"`, `"noise"`, `"glitch"`, `"pixelate"`, `"grayscale"`, `"sepia"`, `"invert"`. Эффект действует на всё окно, вместе с текстом, поэтому для окон с мелким текстом его держат слабым.

## Свои шрифты

Elements загружает шрифт из файла `.ttf` или `.otf` и даёт ему имя: `el_font_add("Elm Serif", путь)`, после чего `el_font_face(e, "Elm Serif")` или стиль `font-family:Elm Serif` ставят его элементу. Шрифт можно встроить и в сам `.exe` — массивом байтов, через `el_font_add_memory`. В папке `examples\elements\fonts` лежат тридцать шрифтов Elements с кириллицей: гротески, геометрический, гуманистический, моноширинный, машинописный, антиквы.

@ 24-шрифты.png | Пример fontshow.c: тридцать шрифтов Elements в нестандартном окне

Примеры шрифтов ищут папку `fonts` рядом с папкой своего `.exe`, на уровень выше. Если программа лежит в другом месте, папку называют переменной окружения `ELFONTS`.

## Ещё возможности

- Меню: `el_menubar` — полоса меню, `el_menu(родитель, "Создать\tCtrl+N")` — пункт с клавишей справа, `el_menu_check` — пункт с галочкой, `el_context_menu` — меню по правой кнопке.
- Готовые окна: `el_message`, `el_ask` с ответом «да» или «нет», `el_toast` — всплывающая строка, `el_open_file`, `el_save_file`, `el_pick_folder`, `el_dialog` — своё модальное окно.
- Анимации: `el_animate(e, "opacity", 0, 255, 400, EL_EASE_OUT, 0)`, появление `el_appear(e, "slide", 300)`, таймеры `el_every`.
- Своё рисование: `el_paint` даёт поверхность, на которой рисуют `el_g_round`, `el_g_line`, `el_g_text`, `el_g_spline`, `el_g_blob` — гладкие кривые любой формы.
- Клавиши окна: `el_hotkey("Ctrl+S", функция, аргумент)`.

## Примеры

Одиннадцать примеров лежат в `examples\elements\demos`, у каждого свой проект `.wccproj` — открыть его в окне WinCC и нажать F5. Из командной строки их собирают просто: `wcc hello.c`.

: custom_window | своя шапка и кнопки окна без рамки Windows
: effects | все эффекты кадра

## Elements и WUI

Обе библиотеки делают окна на GDI+ и обе собираются с программой сами. WUI — это витрина тем ThemeLibrary: шестьдесят одна тема с фактурами, рамками и узорами, выбор темы прямо в заголовке, окно в едином стиле с программами на C#. Elements — конструктор: раскладка как в WPF, привязка элементов к переменным, окна любой формы, эффекты, свои шрифты, стили строкой. В одной программе берут одну из них.

## Итог

Elements подключается строкой `#include <elements.h>` — компилятор сам собирает её с программой. Окно строится один раз деревом элементов, `el_run()` ведёт его до закрытия. Поля, флажки, списки и ползунки пишут прямо в переменные программы, а `el_text_bind` показывает строку программы в окне, так что обработчику достаточно работать с обычными переменными. Панели — столбец, сетка с размерами вида `"Auto,*"`, вкладки, прокрутка — раскладывают элементы сами.

Темы по имени, стили строкой, окна любой формы, эффекты и тридцать своих шрифтов — всё в одной библиотеке. Полный список функций с пояснениями — в `include\elements.h` и `examples\elements\DOCUMENTATION.md`, живые образцы — в `examples\elements\demos`.
