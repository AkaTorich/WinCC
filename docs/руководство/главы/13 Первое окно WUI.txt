# Первое окно WUI
Оконная программа на одном `windows.h` честно показывает, как устроена Windows, но красивой её сделать трудно: кнопки выглядят как у всех, а свой вид требует сотен строк рисования. WUI — библиотека, которая берёт эту работу на себя. Программа говорит, что лежит в окне, — заголовок, поле, кнопку, — а WUI рисует окно целиком в одной из шестидесяти одной темы ThemeLibrary: со своей тенью, скруглёнными углами, заголовком, фоном из стекла, бумаги или металла. Эта глава собирает первое окно, объясняет, что происходит при сборке, и показывает, как программа запоминает выбранную тему.

## Что такое WUI

ThemeLibrary — библиотека тем для программ на WPF (оконной системе .NET). В ней шестьдесят с лишним готовых оформлений: стеклянные, приборные, бумажные, каменные, экранные. WUI повторяет её вид для программ на Си: те же цвета, шрифты, тени, фактуры и рамки, рассчитанные точка в точку. Окно программы на WinCC и окно программы на WPF в одной теме выглядят одинаково.

Устроена WUI иначе, чем окно из девятой главы. Там программа сама регистрирует класс окна, крутит цикл сообщений и на каждое `WM_PAINT` рисует. Здесь всё это делает библиотека, а программа строит дерево элементов. Корень дерева — окно, под ним — столбец содержимого, в столбце — надписи, поля, кнопки, строки и карточки, в них — свои элементы. WUI сама меряет каждый элемент, раскладывает дерево по месту, рисует его в текущей теме и разбирает мышь и клавиатуру. Когда пользователь что-то делает — нажимает кнопку, правит поле, двигает ползунок, — WUI вызывает функцию, которую программа к этому элементу привязала. Такую функцию называют обработчиком события.

Отсюда и порядок работы, общий для всех программ этой части: создать окно, положить в него элементы, привязать обработчики и отдать управление библиотеке. Дальше программа живёт только в обработчиках.

## Первая программа

```
#include <wui.h>

static void close_window(WuiControl *button, void *user)
{
    (void)user;
    wui_window_close(wui_window_of(button));
}

int main(void)
{
    WuiControl *win = wui_window("Первое окно", 720, 400, "FirstWindow");
    WuiControl *page = wui_content(win);
    wui_label(page, "Здравствуй, мир", WUI_LABEL_H1);
    wui_label(page, "Это окно целиком нарисовано библиотекой WUI: тень, скруглённые углы, "
                    "заголовок с кнопками и фон темы.", WUI_LABEL_BODY);
    WuiControl *button = wui_button(page, "Закрыть", WUI_BUTTON_ACCENT);
    wui_on_click(button, close_window, 0);
    return wui_run();
}
```

Собирается программа как любая другая — кнопкой «Собрать» в окне WinCC или командой:

```
wcc first.c
Готово: first.exe — оконная программа, 667136 байт, 3515 мс
```

Окно открывается посреди того монитора, где сейчас мышь. Его можно тащить за заголовок, растягивать за края и углы, разворачивать кнопкой или двойным щелчком по заголовку, сворачивать и закрывать; Alt+F4 тоже закрывает. Развёрнутое окно занимает рабочую область своего монитора и не заходит под панель задач. Ничего из этого программа не писала: всё умеет сама библиотека.

## Строка за строкой

`#include <wui.h>` — единственное, что нужно для подключения. Заголовок сам включает `windows.h` и `gdiplus.h`, объявляет все функции библиотеки и содержит две служебные строки. Первая, `#pragma comment(lib, "wui")`, говорит компилятору взять библиотеку `wui`. Рядом с wcc лежит папка `lib\wui` с её исходниками, поэтому wcc собирает эти исходники вместе с программой, а из готового кода выбрасывает всё, что программа не зовёт (подробнее о `#pragma comment` — в главе 11). Вторая строка, `#pragma comment(linker, "/SUBSYSTEM:WINDOWS")`, делает программу оконной, хотя в ней обычная `main`: при запуске не появится чёрное окно консоли.

`wui_window(заголовок, ширина, высота, ключ)` создаёт окно и возвращает указатель на него. Все элементы WUI, и само окно тоже, — указатели типа `WuiControl *`; что внутри структуры, программе знать не нужно, она только передаёт указатель функциям библиотеки. Ширина и высота — размер самого окна без тени, в точках (о точках — ниже). Последний параметр, ключ, нужен, чтобы помнить выбранную тему; о нём — в конце главы.

`wui_content(win)` даёт столбец содержимого — место под заголовком, куда кладут всё остальное. Элементы в столбце идут сверху вниз в том порядке, в каком их создали, с промежутком в 12 точек. Каждая функция, создающая элемент, первым параметром получает родителя — того, в кого элемент кладётся: `wui_label(page, …)` кладёт надпись в столбец `page`.

`wui_label(родитель, текст, вид)` — надпись. Вид задаёт шрифт и цвет из темы: `WUI_LABEL_H1` — крупный заголовок, `WUI_LABEL_BODY` — книжный текст абзаца. Длинный текст переносится по ширине окна сам. Все тексты в WUI — строки UTF-8, то есть ровно то, что лежит в исходнике, если он сохранён в UTF-8 (а окно WinCC так и сохраняет); кириллица работает без всяких преобразований.

`wui_button(родитель, текст, вид)` — кнопка. `WUI_BUTTON_ACCENT` — главная кнопка окна, цветом акцента темы; остальные виды — в главе 15.

`wui_on_click(кнопка, функция, данные)` привязывает обработчик. Когда кнопку нажмут, WUI вызовет `close_window(кнопка, данные)`. Обработчик у всех элементов один и тот же по виду:

```
void обработчик(WuiControl *c, void *user);
```

Первый параметр — элемент, с которым это случилось, второй — те данные, что переданы третьим параметром в `wui_on_click`. Здесь данные не нужны, поэтому передан ноль, а строка `(void)user;` говорит компилятору, что параметр не забыт, а не нужен. `wui_window_of(button)` находит окно, в котором лежит кнопка, `wui_window_close` его закрывает.

`wui_run()` — цикл сообщений. Пока открыто хоть одно окно программы, функция не возвращается: она принимает сообщения Windows, раскладывает и рисует окна, вызывает обработчики. Когда закрыто последнее окно, `wui_run` возвращает код выхода, и `return wui_run();` отдаёт его системе. По умолчанию код — ноль.

! Всё, что программа делает до `wui_run`, — подготовка: окно ещё не показано. WUI показывает и рисует его, когда начинает работать цикл сообщений, поэтому элементы можно добавлять в любом порядке и сколько угодно — мигать ничего не будет.

## Как WUI рисует окно

Окно WUI — прозрачное по точкам окно Windows (так называемое layered window). Библиотека рисует его целиком в картинку в памяти — тень, фон, элементы, кромку — и отдаёт картинку системе вместе с прозрачностью каждой точки. Поэтому тень у окна настоящая, полупрозрачная, а углы скруглены без зазубрин: за углом действительно виден рабочий стол.

Фон окна — градиент или фактура, пятна света, звёзды, узоры, рамка темы — считается один раз и хранится готовым; при наведении мыши на кнопку перерисовывается только место кнопки поверх этого фона. Фон пересчитывается, когда меняется размер окна, тема или масштаб.

Из этого следует одно ограничение: в окно WUI нельзя положить обычные элементы Windows — кнопки и поля, созданные `CreateWindow` из главы 9. Окно, которое рисуется одной картинкой, их не покажет. Всё, что нужно внутри окна, делается элементами WUI или рисуется на холсте (глава 16); функции Windows, которым окно нужно лишь как хозяин или адресат, — диалог выбора файла, таймер, буфер обмена — работают с ним как обычно.

## Почему exe весит почти мегабайт

Первая программа занимает почти мегабайт (около 870 КБ), а собирается около четырёх секунд — заметно больше, чем `hello.c`. Причины две. Во-первых, wcc каждый раз собирает библиотеку из исходников: так программа не зависит ни от каких файлов, кроме самой Windows. Во-вторых, в программу попадают все шестьдесят одна тема — около 250 КБ палитр, кистей, шрифтов и размеров, — потому что пользователь может выбрать любую. Код фактур, рамок, узоров и всех элементов — остальное. То, чего программа не зовёт, wcc выбрасывает: значки, например, попадают в exe только те, что программа использует.

Готовой программе нужны только DLL Windows. GDI+ (`gdiplus.dll`), которой WUI рисует, есть в каждой Windows начиная с XP. Программу можно отдать одним файлом.

## Окно и консоль

Оконная программа не имеет консоли, и `printf` в ней печатать некуда. Пока программа пишется, консоль бывает нужна — посмотреть, что пришло в обработчик. Для этого достаточно собрать программу ключом `--console`: ключ командной строки сильнее строки в заголовке, и программа получит и окно WUI, и консоль рядом.

```
wcc --console first.c
Готово: first.exe — консольная программа, 892928 байт, 3500 мс
```

То же можно сказать в самом исходнике строкой `#pragma comment(linker, "/SUBSYSTEM:CONSOLE")` после `#include <wui.h>`. Если программа собрана из нескольких файлов, побеждает последняя такая строка по порядку файлов в команде, а каждый файл с `#include <wui.h>` несёт свою строку `/SUBSYSTEM:WINDOWS`, — поэтому ключ `--console` надёжнее. Готовую программу собирают без него.

## Точки и масштаб экрана

Размеры в WUI задаются не в пикселях, а в точках DIP — так же, как в WPF. Точка — это пиксель при обычном масштабе экрана в 100 %, то есть 1/96 дюйма. Если в параметрах Windows стоит масштаб 150 %, окно `720 × 400` займёт на экране 1080 × 600 пикселей, и всё в нём — шрифты, поля, тени — будет крупнее во столько же раз. Программа об этом не думает: она пишет размеры в точках, а WUI умножает их на масштаб того монитора, где стоит окно. Если перетащить окно на монитор с другим масштабом, оно перерисуется под него само.

Ширина и высота в `wui_window` — размер окна без тени: тень рисуется вокруг, в прозрачной полосе, которая к размеру добавляется. Если окно не помещается на монитор, WUI его уменьшает. Меньше чем 360 × 240 точек пользователь окно не сожмёт; свой предел ставит `wui_window_min_size(win, ширина, высота)` — полезно, когда при узком окне раскладка теряет смысл. Строку заголовка WUI бережёт сама: когда окно сужают и она перестаёт помещаться, первым прячется название окна, а значок, то, что лежит в строке заголовка справа, и кнопки окна остаются на местах. Уже их окно мышью не сжимается, так что кнопки окна за край не уходят.

## Тема и её выбор

Окно открылось в теме «Изумруд и золото» — она первая в списке и стоит по умолчанию. Чтобы пользователь мог выбрать другую, достаточно одной строки:

```
wui_theme_picker(wui_titlebar(win));
```

`wui_titlebar(win)` даёт строку в заголовке окна, справа, перед кнопками «свернуть», «развернуть» и «закрыть». `wui_theme_picker` кладёт туда раскрывающийся список всех тем, разбитых на группы: «Стекло», «Приборы», «Пергамент», «Камень», «Самоцветы», «Древние миры», «Магия и наука», «Экраны», «Природа», «Материалы», «Плоские». Выбранная тема ложится сразу на все окна программы, без перезапуска. Если программе нужно знать, что тему сменили, к списку привязывают обработчик изменения (глава 16).

Вот программа побольше: с выбором темы, подзаголовком, значком и полем, которое что-то делает.

```
#include <wui.h>
#include <stdio.h>

static WuiControl *g_win, *g_name;

static void greet(WuiControl *c, void *user)
{
    (void)c; (void)user;
    char text[200];
    const char *name = wui_get_text(g_name);
    if (*name) snprintf(text, sizeof text, "Здравствуйте, %s!", name);
    else snprintf(text, sizeof text, "Сначала впишите имя");
    wui_toast(g_win, text);
}

int main(void)
{
    g_win = wui_window("Приветствие", 760, 400, "Greeting");
    wui_window_subtitle(g_win, "пример WUI");
    wui_window_logo(g_win, WUI_ICON_CHAT);
    wui_theme_picker(wui_titlebar(g_win));

    WuiControl *card = wui_card(wui_content(g_win), "Знакомство");
    wui_label(card, "Впишите имя и нажмите кнопку или Enter.", WUI_LABEL_DIM);
    g_name = wui_textbox(card, "Как вас зовут?");
    WuiControl *button = wui_button(card, "Поздороваться", WUI_BUTTON_ACCENT);
    wui_on_click(button, greet, 0);
    wui_on_click(g_name, greet, 0);         // Enter в поле — то же, что кнопка
    return wui_run();
}
```

`wui_window_subtitle` пишет бледный подзаголовок рядом с названием окна, `wui_window_logo` ставит слева значок из набора ThemeLibrary (все 123 значка — в приложении Г). `wui_card` — карточка, панель темы с заголовком; в ней элементы тоже идут столбцом. `wui_textbox` — поле ввода с подсказкой, которая видна, пока поле пустое. `wui_get_text` читает из поля текст в UTF-8, `wui_toast` показывает внизу окна строку, которая гаснет сама через две-три секунды.

Обработчик `greet` привязан и к кнопке, и к полю. У поля «щелчок» — это Enter: так форма отвечает на клавиатуру без лишнего кода. Указатели на окно и поле лежат в глобальных переменных: обработчику нужны элементы, которых ему не передали, а программа с одним окном проще всего держит их так. Другой способ — передать нужный указатель через параметр `user`; он показан в следующих главах.

## Ключ: где помнится тема

Выбор темы WUI запоминает сама. Для этого и нужен четвёртый параметр `wui_window` — ключ, короткое имя программы латиницей. Выбранная тема записывается в файл `%APPDATA%\ThemeLibrary\ключ.theme` — одна строка с именем темы, например `Parchment`. При следующем запуске `wui_window` читает этот файл и открывает окно сразу в нужной теме.

Хранилище то же, что у самой ThemeLibrary. Поэтому программа на Си и программа на WPF с одинаковым ключом делят одну тему: выбрали «Сапфир» в одной — вторая при запуске тоже откроется в «Сапфире». Если такое родство не нужно, ключ берут свой, у каждой программы разный: `"Greeting"`, `"Expenses"`, `"FirstWindow"`.

Если вместо ключа передать ноль, тема не запоминается: программа каждый раз открывается в «Изумруде и золоте», а выбор в списке живёт до её закрытия. Так делают с пробными программами и служебными окнами. В программе с несколькими окнами действует ключ первого окна, у которого он задан; ключи остальных окон ничего не меняют, а тема и так одна на все окна.

! Файл темы пишется только тогда, когда тему меняют, — выбором в списке или вызовом `wui_theme_set`. Программа, которой ни разу не меняли тему, ничего в `%APPDATA%` не оставляет.

## Заголовок окна

Заголовок — тоже часть дерева, и программа может в нём кое-что менять.

:= Что сделать | Как
: Сменить название окна | `wui_text(win, "Новое название")` — меняется и в заголовке, и на панели задач
: Добавить подзаголовок | `wui_window_subtitle(win, "текст")`
: Поставить значок слева | `wui_window_logo(win, WUI_ICON_…)`
: Положить свои элементы справа | создавать их в `wui_titlebar(win)`: выбор темы, тихую кнопку со значком
: Убрать плашку заголовка | `wui_window_extend(win, 1)` — содержимое до самого верха, об этом в главе 16

Строка `wui_titlebar` — обычная строка WUI: в неё можно положить и кнопку, и надпись. Например, тихая кнопка со значком «справка» рядом с выбором темы делается так же, как любая кнопка (глава 15), только родителем у неё будет `wui_titlebar(win)`.

## Когда программа заканчивается

Программа на WUI заканчивается, когда закрыто её последнее окно: `wui_run` возвращается, и `main` выходит. Закрыть окно из программы можно двумя способами.

- `wui_window_close(win)` закрывает одно окно. Если оно последнее, программа завершится с кодом 0.
- `wui_quit(код)` закрывает все окна сразу, и `wui_run` вернёт переданный код. Так программа сообщает о неудаче тому, кто её запустил, например командному файлу.

Перехватить закрытие окна — спросить «сохранить ли?» — WUI не даёт: крестик в заголовке закрывает окно сразу. Поэтому программы на WUI сохраняют данные по ходу работы, после каждого изменения; так устроена и программа главы 17.

## Итог

Окно WUI — это дерево элементов: `wui_window` создаёт корень, `wui_content` даёт столбец под заголовком, функции элементов кладут в него надписи, поля и кнопки, `wui_on_click` привязывает обработчики, `wui_run` отдаёт управление библиотеке до закрытия последнего окна. Подключается всё одной строкой `#include <wui.h>`: wcc сам собирает библиотеку из `lib\wui`, делает программу оконной и выбрасывает лишнее; готовый exe весит около мегабайта и не требует ничего, кроме Windows.

Размеры пишутся в точках, а масштаб экрана WUI учитывает сама. Тему выбирает пользователь списком `wui_theme_picker`, а ключ в `wui_window` говорит, под каким именем этот выбор помнить. Следующая глава — о том, как раскладывать элементы по окну: столбцы, строки, доли, поля и прокрутка.
